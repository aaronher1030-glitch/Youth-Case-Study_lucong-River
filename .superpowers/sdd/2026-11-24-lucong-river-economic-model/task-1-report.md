## What was implemented

### Task 1: Input contracts, census loader, and provenance register

- Created the `river_model` package.
- Added frozen `Shed` and `Params` dataclasses. `Params` has all 55 fields and the exact defaults specified in the brief.
- Added `load_census(path)` using `csv.DictReader`. It:
  - requires the five declared census columns;
  - rejects blank IDs, duplicate IDs, non-integer heads, heads below 1, and drainage tokens other than `true`, `false`, or `unknown`;
  - preserves CSV row order and returns a tuple;
  - supports UTF-8 BOM input.
- Added `eligible_sheds(sheds)`, which includes only rows whose drainage value is exactly `True`.
- Added immutable `apply_overrides(params, overrides)`:
  - rejects unknown names;
  - parses integer and floating-point fields according to their declared types;
  - accepts `None` for optional parameters, including resetting an already-populated optional parameter;
  - rejects `None` for non-optional parameters;
  - returns a new `Params` instance without modifying the input.
- Added `parameter_register(params)`, returning one row per `Params` field with `name`, `value`, `unit`, `status`, and `source`.
  - `PARAMETER_META` covers every field exactly once.
  - The register raises `ValueError` for missing or extra metadata names and malformed metadata keys.
  - `land_available_ha` and `upstream_mpn_100ml` are marked `missing`.
  - `q_m3_s`, `e_head_day`, and `eta` are marked `assumption`, with source text requiring field measurement or literature verification.
  - `c0_mpn_100ml`, `ch4_mj_m3`, and `lpg_mj_kg` are marked `sourced`.
  - Targets, budget, durations, focus share, and design limits are marked `design`.

### Task 1A: Seeded synthetic census generator

- Added frozen `SyntheticSpec` with the exact prior defaults from the brief.
- Added `generate_synthetic_census(spec, scenario_id, seed)`:
  - validates shed bounds, triangular head bounds, connection probabilities, barangay uniqueness, scenario count, and scenario ID;
  - uses `numpy.random.default_rng(seed)` for reproducibility;
  - generates 12–20 sheds by default with integer heads in the declared 8–25 range;
  - assigns unique scenario/index IDs and a declared barangay;
  - labels every row with `synthetic;`, scenario, seed, and prior details.
- Added `write_census(path, sheds)`:
  - creates parent directories;
  - writes the declared CSV schema;
  - serializes `True`, `False`, and `None` as `true`, `false`, and `unknown`;
  - round-trips through `load_census`.
